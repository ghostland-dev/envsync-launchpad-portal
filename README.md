# EnvSync Launchpad

Environment management portal, packaged for web and mobile with Capacitor.

## Features

- Environment overview
- Android/iOS builds via Capacitor
- Push and local notifications

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Framer Motion
- Capacitor

## Getting Started

```bash
git clone https://github.com/ghostland-dev/envsync-launchpad-portal.git
cd envsync-launchpad-portal
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
